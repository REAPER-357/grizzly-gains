Google Sheets Setup (2 minutes)

  1. Create a new Google Sheet, then open Extensions ▸ Apps Script.
  2. Delete what’s there and paste the script below. Click Save.
  3. Deploy ▸ New deployment ▸ Web app. Execute as Me, access Anyone. Deploy and approve the permissions.
  4. Copy the Web app URL, paste it in Settings ▸ Cloud Backup, tap Save & Test.
  5. Optional: share that sheet (Anyone with link ▸ Viewer) so others can import your Exercises tab.
