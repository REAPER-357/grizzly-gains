# 🏋️ Grizzly Gains

**Grizzly Gains** is a lightweight, offline-first personal weight lifting and body weight tracker built with vanilla HTML, CSS, and JavaScript. No servers, no bloat, and total privacy—all your data lives right in your browser's `localStorage`.

---

## ✨ Features

* **Workout Management:** Create, edit, and delete custom workout routines with up to 10 exercises per routine.
* **Active Workout Sessions:** Log your sets, weights, and reps with real-time indicators showing what you lifted *last time* for that exact set.
* **Exercise Progress Graphs:** Visualize your max weight progress over time for any exercise using an offline HTML5 Canvas line graph.
* **Body Weight Tracker:** Log your daily body weight and view your complete history at a glance.
* **Workout History:** Review past completed workout summaries.
* **Data Backup & Restore:** Easily export your entire database to a `.json` file and restore it whenever needed.
* **100% Offline Capable:** Runs instantly from a single local file or progressive web setup.

---

## 🚀 How to Run

1. Make sure you have your `index.html` file and your `icon.png` in the same folder.
2. Simply double-click `index.html` to open it directly in any modern web browser (Chrome, Safari, Firefox, Edge).

---

## 💾 Data Backup & Recovery

Because all data is stored locally via `localStorage`:
* Go to **Manage Workouts** to find the **Data Backup & Restore** section.
* Click **Export Workouts (.json)** to download a backup file of your history and routines.
* Use **Import Workouts** to restore your data on a new device or browser.
